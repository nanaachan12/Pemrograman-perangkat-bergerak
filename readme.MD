## 📌 Deskripsi Singkat  
Crypto Tracker adalah aplikasi mobile sederhana dan intuitif untuk memantau harga cryptocurrency secara real-time.  
Aplikasi ini dibangun menggunakan **Ionic Vue**, **TailwindCSS**, dan data dari **CoinLore API** serta **Frankfurter API**.

---

## 🚀 Fitur Utama  
### 🔹 Real-time Crypto Price  
Menampilkan harga crypto terkini, market cap, volume, dan perubahan harga (1h, 24h, 7d).

### 🔹 Konversi Mata Uang  
Mendukung USD ⇄ IDR secara dinamis menggunakan Frankfurter API.

### 🔹 Pencarian & Sorting  
- Cari berdasarkan nama atau simbol  
- Sort by Rank, Nama (A-Z), atau Harga  

### 🔹 Detail Koin  
Menampilkan modal berisi informasi lengkap seperti:
- Harga  
- Perubahan 1h/24h/7d  
- Volume, Market Cap  
- Total Supply, Circulating Supply  

### 🔹 UI Responsif & Dark Mode  
Tampilan mirip mobile-emulator saat di desktop, dan mendukung Light/Dark Mode.
